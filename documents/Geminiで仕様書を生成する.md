# Gemini 経由で仕様書を生成する

Google Gemini API を使用して、Workato プロジェクトの仕様書を自動生成する手順です。
Dify と異なり、ファイルアップロードは不要で、プロンプト + JSON を直接送信するシンプルな構成です。

## 前提条件

- Google AI Studio で Gemini API キーを取得済みであること

---

## 1. プロファイルの作成（初回のみ）

Settings ページで Gemini の接続先プロファイルを作成します。

1. サイドバーから **Settings** を開く
2. **Gemini** セクションの「追加」をクリック
3. 以下を入力して保存する

| 項目 | 入力内容 |
|------|----------|
| 名前 | 任意のプロファイル名（例: `本番Gemini`） |
| API キー | Google AI Studio で発行した API キー（`AIza...` で始まる文字列） |
| モデル | 使用するモデルを選択（Gemini 2.5 Flash / 2.5 Pro / 2.0 Flash / 1.5 Pro / 1.5 Flash） |

4. 右上の「保存」ボタンをクリック

---

## 2. プロジェクトの JSON を取得する

Projects ページから対象プロジェクトの JSON を取得します。

1. サイドバーから **Projects** を開く
2. 対象のプロジェクトをクリックして詳細ページへ遷移
3. レシピ一覧で、エクスポートに含めたいレシピにチェックを入れる
4. **EP（エントリーポイント）カラム** で、エントリーポイントにしたいレシピにチェックを入れる
   - EP にチェックを入れたレシピが、仕様書の起点として扱われます
   - 複数選択可能です（マルチエントリーポイント対応）
5. 「**プレビュー**」ボタンをクリック
6. JSON プレビューモーダルが開く
7. 「**クレンジング**」ボタンをクリック
   - LLM に不要なプロパティが除去され、トークン消費を削減できます
8. 「**コピー**」ボタンをクリックして JSON をクリップボードにコピー

---

## 3. Gemini ページで仕様書を生成する

1. サイドバーから **Gemini** を開く

### プロンプト入力

- 上部のテキストエリアに仕様書生成用のプロンプトを入力します
- プロンプトテンプレートは `documents/仕様書生成用プロンプト.md` を参考にしてください
- プロンプトは保存・読み込みが可能です
  - 「**保存**」アイコンで現在のプロンプトを名前を付けて保存
  - 「**読み込み**」アイコンで保存済みのプロンプトを選択して復元

### JSON 入力

- 下部のテキストエリアに、手順2でコピーした JSON をペースト

### 実行

2. 両方の入力が完了したら「**実行**」ボタンをクリック
3. Gemini API に直接リクエストが送信されます（ファイルアップロードは不要）
4. 完了後、結果エリアに仕様書が表示されます

### 結果の確認

| 操作 | 説明 |
|------|------|
| 編集 | マークダウンエディタページで仕様書を編集 |
| 保存 | .md ファイルとしてダウンロード |
| API タブ | リクエスト・レスポンスの詳細（デバッグ用） |

---

## Dify との違い

| 項目 | Gemini | Dify |
|------|--------|------|
| 入力 | プロンプト + JSON（2つのテキストエリア） | JSON のみ（ワークフロー側にプロンプトが組み込み済み） |
| ファイルアップロード | なし（直接送信） | あり（Dify File API 経由） |
| 実行ステップ | 1ステップ | 2ステップ（アップロード → ワークフロー実行） |
| Draw.io 出力 | プロンプト次第 | ワークフローの出力変数で制御 |
| プロンプト管理 | アプリ内で保存・読み込み可能 | Dify ワークフロー側で管理 |

---

## 補足

- Gemini はプロンプトを自分で管理するため、自由度が高い反面、プロンプトの品質が出力に直結します
- 実行履歴は **History** ページで確認・再閲覧できます
