# Dify 経由で仕様書を生成する

Dify ワークフローを使用して、Workato プロジェクトの仕様書を自動生成する手順です。

<br>

## 前提条件

- Dify のワークフローが構築済みであること
- Dify の API URL と API キーを取得済みであること

> [!TIP]
> ワークフローは `documents/仕様書生成（Workato）.yml` をインポートして作成することを推奨します。
> Dify の「DSLをインポート」機能でこの YAML ファイルを読み込むと、仕様書生成用ワークフローが自動構築されます。

<br>

## 1. プロファイルの作成（初回のみ）

Settings ページで Dify の接続先プロファイルを作成します。

1. サイドバーから **Settings** を開く
2. **Dify** セクションの「追加」をクリック
3. 以下を入力して保存する

| 項目 | 入力内容 |
|------|----------|
| 名前 | 任意のプロファイル名（例: `本番Dify`） |
| API URL | Dify の API エンドポイント（例: `https://api.dify.ai/v1`） |
| API キー | Dify ワークフローの API キー（`app-` で始まる文字列） |

4. 右上の「保存」ボタンをクリック

<br>

## 2. プロジェクトの JSON を取得する

Projects ページから対象プロジェクトの JSON を取得します。

1. サイドバーから **Projects** を開く
2. 対象のプロジェクトをクリックして詳細ページへ遷移
3. レシピ一覧で、エクスポートに含めたいレシピにチェックを入れる
4. **EP（エントリーポイント）カラム** で、エントリーポイントにしたいレシピにチェックを入れる
   - EP にチェックを入れたレシピが、仕様書の起点として扱われます
   - 複数選択可能です（マルチエントリーポイント対応）
5. 「**プレビュー**」ボタンをクリック
6. JSON プレビューモーダルが開く
7. 「**クレンジング**」ボタンをクリック
8. 「**コピー**」ボタンをクリックして JSON をクリップボードにコピー

> [!IMPORTANT]
> 「クレンジング」は必ず実行してください。LLM に不要なプロパティが除去され、トークン消費を大幅に削減できます。

<br>

## 3. Dify ページで仕様書を生成する

1. サイドバーから **Dify** を開く

<br>

### ファイル API 設定（セクション1）

| 項目 | 説明 |
|------|------|
| Json情報の入力変数 | Dify ワークフロー側で定義したファイル入力変数名（デフォルト: `file`） |
| JSON 入力欄 | 手順2でコピーした JSON をペースト |

<br>

### ワークフロー設定（セクション2）

| 項目 | 説明 |
|------|------|
| ユーザー（必須） | ワークフロー実行者の識別名（例: `user-001`） |
| レスポンスモード（必須） | `Streaming` または `Blocking` を選択 |
| カスタム入力変数 1〜4 | Dify ワークフローに追加のパラメータを渡す場合に使用（任意） |
| マークダウンの出力変数 | ワークフロー出力からマークダウンを取得するキー名（デフォルト: `text`） |
| draw の出力変数 | ワークフロー出力から Draw.io XML を取得するキー名（デフォルト: `drawio_xml`） |

> [!TIP]
> Cloudflare 環境では、レスポンスモードは `Streaming` を推奨します。

> [!NOTE]
> `仕様書生成（Workato）.yml` からインポートしたDifyワークフローを使用する場合は、出力変数を以下のように設定してください。
> - **マークダウンの出力変数**: `spec`
> - **draw の出力変数**: `xml`

<br>

### 実行

2. 設定が完了したら「**実行**」ボタンをクリック
3. 確認ダイアログで「実行」を選択
4. ファイルアップロード → ワークフロー実行の2ステップで処理が進行します
5. 完了後、結果タブに仕様書が表示されます

<br>

### 結果の確認

| タブ | 内容 |
|------|------|
| マークダウン | 生成された仕様書のプレビュー。「編集」でマークダウンエディタへ、「保存」で `.md` ファイルとしてダウンロード |
| draw.io | フローチャートのプレビュー。「保存」で `.drawio` ファイルとしてダウンロード |
| ファイル API | ファイルアップロードの curl コマンドとレスポンス（デバッグ用） |
| ワークフロー API | ワークフロー実行の curl コマンドとレスポンス（デバッグ用） |

<br>

## 補足

> [!NOTE]
> - ワークフロー設定の各パラメータはプロファイルごとに自動保存されます（500ms デバウンス）
> - 実行中にページを離れても、戻ってくれば経過時間が継続表示されます
> - 実行履歴は **History** ページで確認・再閲覧できます
