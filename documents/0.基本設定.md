# 基本設定

本アプリを使用するために必要な初期設定の手順です。

<br>

## Workato プロファイルの作成（必須）

Workato API への接続プロファイルは**必須**です。これがないとプロジェクトやレシピの情報を取得できません。

> [!CAUTION]
> Workato プロファイルが未設定の場合、Projects・Recipes・Connections・Jobs の各ページは使用できません。

<br>

### 設定手順

1. サイドバーから **Settings** を開く
2. **Workato** セクションの「追加」をクリック
3. 以下を入力して保存する

| 項目 | 入力内容 |
|------|----------|
| 名前 | 任意のプロファイル名（例: `本番環境`） |
| Base URL | Workato の API エンドポイント（例: `https://www.workato.com/api` または `https://app.jp.workato.com/api`） |
| API トークン | Workato で発行した API トークン |

4. 右上の「保存」ボタンをクリック

<br>

### API トークンの発行方法

Workato の API トークンは、Workato の管理画面から発行します。

> [!TIP]
> 詳しい手順は Workato 公式ドキュメントを参照してください。
> https://docs.workato.com/ja/workato-api.html

<br>

### 複数環境の管理

プロファイルは複数作成できます。本番環境・検証環境など、用途に応じて使い分けてください。
Settings ページ上部のドロップダウンでアクティブなプロファイルを切り替えられます。

<br>

## プロキシの設定（社内ネットワークで使用する場合）

社内ネットワークなど、インターネット接続にプロキシが必要な環境では、プロキシの設定が必要です。

> [!IMPORTANT]
> プロキシを設定しないと、社内ネットワークから Workato API や Dify / Gemini API に接続できない場合があります。

<br>

### 設定手順

1. Settings ページ上部の **プロキシ URL** 欄に、プロキシサーバーの URL を入力する
   - 例: `http://proxy.example.com:8080`
2. 各プロファイル（Workato / Dify / Gemini 等）で **プロキシを使用** を ON にする

> [!NOTE]
> プロキシ URL はすべてのプロファイルで共通です。プロファイルごとにプロキシの ON / OFF を切り替えられます。

<br>

## 画面の拡大率

Settings ページから画面の拡大率（ズーム）を変更できます。表示が小さい・大きいと感じた場合に調整してください。

<br>

## データフォルダ

Settings ページの「データフォルダ」から、アプリの設定ファイルやログが保存されているフォルダを開けます。
設定のバックアップやトラブルシューティングの際に使用してください。

<br>
