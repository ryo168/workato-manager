# 別途 LLM で仕様書を生成する

ChatGPT、Copilot、Claude などの外部 LLM を使用して、Workato プロジェクトの仕様書を手動で生成する手順です。
本アプリの Dify / Gemini 連携機能を使わず、任意の LLM に直接プロンプトと JSON を渡して仕様書を作成します。

<br>

## 前提条件

- 使用する LLM のアカウントまたはデスクトップアプリが利用可能であること
  - 例: ChatGPT（Web / デスクトップアプリ）、Microsoft Copilot、Claude、Gemini（Google AI Studio）など
- `documents/仕様書生成用プロンプト.md` を手元に用意しておくこと

<br>

## 1. プロジェクトの JSON を取得する

Projects ページから対象プロジェクトの JSON を取得します。

1. サイドバーから **Projects** を開く
2. 対象のプロジェクトをクリックして詳細ページへ遷移
3. レシピ一覧で、エクスポートに含めたいレシピにチェックを入れる
4. **EP（エントリーポイント）カラム** で、エントリーポイントにしたいレシピにチェックを入れる
   - EP にチェックを入れたレシピが、仕様書の起点として扱われます
   - 複数選択可能です（マルチエントリーポイント対応）
5. 「**プレビュー**」ボタンをクリック
6. JSON プレビューモーダルが開く
7. 「**クレンジング**」ボタンをクリック
8. 「**コピー**」ボタンをクリックして JSON をクリップボードにコピー

> [!IMPORTANT]
> 「クレンジング」は必ず実行してください。LLM に不要なプロパティが除去され、トークン消費を大幅に削減できます。

<br>

## 2. プロンプトを準備する

1. `documents/仕様書生成用プロンプト.md` の内容をコピーする
2. プロンプトの末尾に、手順1でコピーした JSON を貼り付ける

以下のような構成になります：

```
（仕様書生成用プロンプト.md の内容）

# 入力JSONテキスト

（手順1でコピーした JSON）
```

<br>

## 3. LLM に送信して仕様書を生成する

準備したプロンプト + JSON を LLM に送信します。

| LLM | 手順 |
|-----|------|
| **ChatGPT**（Web / デスクトップアプリ） | 新しいチャットを開き、プロンプト + JSON を貼り付けて送信 |
| **Microsoft Copilot** | Copilot を開き、プロンプト + JSON を貼り付けて送信 |
| **Claude** | 新しい会話を開き、プロンプト + JSON を貼り付けて送信 |
| **Google AI Studio** | 新しいプロンプトを作成し、プロンプト + JSON を貼り付けて実行 |

<br>

## 4. 結果の確認・保存

- 生成されたマークダウンをコピーし、`.md` ファイルとして保存してください
- Draw.io の XML が出力された場合は、XML 部分を `.drawio` ファイルとして保存してください

> [!TIP]
> 本アプリの **Markdown Editor** ページを使えば、生成結果を貼り付けてプレビュー確認・ファイル保存が可能です。

<br>

## コンテキストウィンドウに関する注意

> [!WARNING]
> LLM にはモデルごとに **一度に処理できるトークン数の上限（コンテキストウィンドウ）** があります。
> プロンプトと JSON の合計がこの上限を超えると、回答が途中で切れたり、正確な仕様書が生成できない場合があります。

<br>

### 各 LLM のコンテキストウィンドウ（目安）

| LLM | コンテキストウィンドウ |
|-----|----------------------|
| ChatGPT（GPT-4o） | 約 128,000 トークン |
| Microsoft Copilot | 利用プランにより異なる |
| Claude（Sonnet / Opus） | 約 200,000 トークン |
| Gemini（2.5 Pro） | 約 1,000,000 トークン |

<br>

### 上限を超えそうな場合の対策

- **クレンジング機能を必ず使用する** — 手順1の「クレンジング」で不要なプロパティを除去し、JSON のサイズを削減してください
- **レシピを絞り込む** — プロジェクト内の全レシピではなく、必要なレシピのみを選択してエクスポートしてください
- **分割して生成する** — JSON が大きすぎる場合は、エントリーポイント単位で分割し、複数回に分けて生成することを検討してください

<br>

## Dify / Gemini 連携との違い

| 項目 | 別途 LLM | Dify | Gemini |
|------|----------|------|--------|
| 利用するツール | 外部アプリ（ChatGPT 等） | 本アプリの Dify ページ | 本アプリの Gemini ページ |
| プロンプト管理 | 手動でコピー＆ペースト | Dify ワークフロー側で管理 | アプリ内で保存・読み込み |
| 実行履歴 | なし（LLM 側の履歴に依存） | History ページで確認可能 | History ページで確認可能 |
| Draw.io 出力 | プロンプト次第 | ワークフローの出力変数で制御 | プロンプト次第 |
| 手軽さ | 環境を問わずすぐ使える | 初回セットアップが必要 | APIキーの取得が必要 |

> [!NOTE]
> Dify / Gemini 連携を使うと、プロンプト管理や実行履歴の確認がアプリ内で完結します。
> 頻繁に仕様書を生成する場合は、連携機能のセットアップをおすすめします。
